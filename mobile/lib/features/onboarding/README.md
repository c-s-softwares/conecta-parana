# Onboarding Conecta Paraná

Pasta de recursos de onboarding para novos desenvolvedores do projeto Conecta Paraná. Aqui você encontrará links para vídeos tutoriais que cobrem a configuração inicial do ambiente, arquitetura do projeto e respostas para dúvidas frequentes.

## O que é esta pasta?

A pasta `/onboarding` centraliza links para vídeos guia (hospedados no YouTube) para desenvolvedores que estão entrando no projeto. Cada vídeo é um recurso prático que facilita o aprendizado sobre a estrutura, setup e boas práticas do Conecta Paraná.

## Vídeos Disponíveis

### Setup e Dúvidas Gerais

**Link**: [Assista no YouTube](https://youtu.be/AZiXKGK3O0w)

Vídeo completo que detalha o processo de setup inicial e a arquitetura do projeto. Essencial para novos desenvolvedores.

**Tópicos cobertos**:

- Documentação e requisitos: stack tecnológica (NestJS, Angular, Flutter, Docker, Prisma, etc.)
- Configuração de ambiente (.env)
- Orquestração com Docker Compose para infraestrutura (PostgreSQL, Redis)
- Estrutura do monorepo e backend: módulos NestJS, validações com Zod, Prisma ORM
- Desenvolvimento do frontend (Admin): estrutura Angular, rotas e comunicação com API
- Desenvolvimento do frontend (Mobile) : instalação, estrutura Flutter, inicialização da aplicação (via chrome e emulador)
- Fluxo de trabalho e boas práticas: documentação, estratégias de branches e padrões de código

**Público-alvo**: Todos os novos desenvolvedores, independentemente da especialidade (backend, frontend, mobile ou DevOps).

## Como usar

1. Reproduza o vídeo correspondente ao seu interesse
2. Tome notas das partes relevantes para sua stack
3. Aplique os passos mostrados no seu ambiente local
4. Consulte a documentação adicional conforme necessário:
   - [README.md](../README.md) - Documentação geral do projeto
   - [docs/SETUP.md](../docs/SETUP.md) - Guia detalhado de configuração
   - [docs/](../docs) - Documentação técnica completa

## Próximos passos

Após assistir aos vídeos:

1. Configure seu ambiente local seguindo os passos mostrados
2. Explore a estrutura do projeto nas pastas `/backend`, `/admin`, `/mobile`
3. Familiarize-se com as estratégias de branches do projeto
4. Revise os padrões de código e convenções estabelecidas
5. Entre em contato com o time se tiver dúvidas não cobertas pelos vídeos

## Notas

- Todos os vídeos estão em português brasileiro
- Reserve tempo para pausar, praticar e replicar os passos
- Os vídeos refletem a arquitetura atual do projeto — sempre valide com a documentação mais recente
- Esta pasta está em evolução e novos vídeos e recursos serão adicionados conforme necessário
